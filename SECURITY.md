# Security policy

## Supported versions

Keepygaga RAG is pre-alpha software and has no supported release series yet.
Security fixes are made only on the latest default branch; older commits and
local forks are not supported.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** button under the repository's
**Security → Advisories** page. This creates a private report visible only to
the reporter and repository maintainers.

Do not open a public issue, pull request, or discussion for a suspected
vulnerability. Do not include API keys, source documents, index contents, or
other personal data in public GitHub content.

Include the affected commit or version, impact, reproduction steps, and any
suggested mitigation. Reports are handled on a best-effort basis; no response or
remediation timeline is guaranteed.
