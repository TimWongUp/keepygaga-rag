# Rename the product to Keepygaga RAG

**Status:** accepted

Before the first public package release, rename Keepygaga Knowledge to Keepygaga RAG and align the repository, distribution, Python package, CLI, configuration, environment variables, diagnostic schemas, and MCP display name around `keepygaga-rag` / `keepygaga_rag`. KagaRAG was shorter, but retaining the full Keepygaga name makes the relationship to the parent project explicit; `rag` is already the established retrieval boundary and MCP host identity.
